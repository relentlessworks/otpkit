otpkit

Agentic-first TOTP and HOTP generation and verification service

Go RFC 6238 RFC 4226 MCP MIT
GitHub Docs

Principles

Agent IS the Interface

No UI, no SDK. The API is the product. Every endpoint designed for AI agents.

Plain Text by Default

One grepable line per record. Token-cheap. JSON on demand via ?format=json.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual.

Single Binary

Go + zero external deps. CGO_ENABLED=0. Deploys as one file.

MCP Connector

Speaks Model Context Protocol at /mcp with 10 tools.

Quick Start

$ make build
$ ./otpkit

# Generate a TOTP code
$ curl "http://localhost:8470/totp?secret=JBSWY3DPEHPK3PXP"
code=123456 digits=6 period=30 algorithm=SHA1 remaining=25

# Verify a TOTP code
$ curl "http://localhost:8470/totp/verify?secret=JBSWY3DPEHPK3PXP&code=123456"
valid=true window=1

# Generate a new secret
$ curl "http://localhost:8470/secret"
secret=KRSXG5BAIFAUKVTFNFGGYZLTNE bytes=20

# Generate otpauth:// URI
$ curl "http://localhost:8470/uri?secret=JBSWY3DPEHPK3PXP&label=alice&issuer=ACME"
uri=otpauth://totp/ACME:alice?secret=JBSWY3DPEHPK3PXP&... type=totp label=alice

API Endpoints

GET /totp

Generate time-based OTP (RFC 6238)

GET /totp/verify

Verify TOTP with clock drift window

GET /hotp

Generate counter-based OTP (RFC 4226)

GET /hotp/verify

Verify HOTP with look-ahead window

GET /secret

Generate random base32 secret

GET /uri

Generate otpauth:// URI for authenticator apps

GET /totp/remaining

Seconds left in current window

POST /mcp

MCP JSON-RPC 2.0 with 10 tools
